水印照片保存在哪里？

拍摄后的水印照片会自动保存到系统相册。若未保存成功，请前往「系统设置 → 隐私与安全性 → 照片」中确认本 App 的权限为「允许添加照片」。

相机权限

App 需要相机权限才能拍摄。若未授权，请前往「系统设置 → 隐私与安全性 → 相机」中开启权限，然后重启 App。

地点水印不显示或位置不对

地点水印需要定位权限。请前往「系统设置 → 隐私与安全性 → 定位服务」中开启，并确保本 App 已允许使用定位。在室内或弱信号环境下，定位可能不够精确。

天气水印在哪里？

天气水印为 Pro 功能，解锁 Pro 后选择含天气的模板即可使用。天气数据由 Apple WeatherKit 提供。

如何恢复 Pro 购买？

若已购买 Pro 但未生效，请在设置页点击「恢复购买」。若仍无法恢复，请邮件联系我们并提供 App Store 的购买凭证截图。

Where are watermarked photos saved?

Watermarked photos are saved to your system photo library automatically. If a photo was not saved, go to "System Settings → Privacy & Security → Photos" and make sure this app is set to "Add Photos".

Camera Permission

The app needs camera access to take photos. If not authorized, enable it in "System Settings → Privacy & Security → Camera", then restart the app.

Location watermark missing or inaccurate

The location watermark requires location access. Please enable it in "System Settings → Privacy & Security → Location Services" and make sure this app is allowed to use your location. Indoors or with weak signals, location may be less accurate.

Where is the weather watermark?

The weather watermark is a Pro feature. After unlocking Pro, choose a template that includes weather. Weather data is provided by Apple WeatherKit.

How do I restore a Pro purchase?

If you've purchased Pro but it hasn't taken effect, tap "Restore Purchases" on the Settings page. If it still doesn't work, email us with a screenshot of your App Store receipt.

ウォーターマーク付き写真はどこに保存されますか？

撮影したウォーターマーク付き写真は、システムのフォトライブラリに自動的に保存されます。保存されない場合は、「システム設定 → プライバシーとセキュリティ → 写真」で本アプリの権限が「写真を追加」になっているかご確認ください。

カメラ権限

アプリは撮影のためにカメラへのアクセスを必要とします。未許可の場合は「システム設定 → プライバシーとセキュリティ → カメラ」で許可し、アプリを再起動してください。

位置情報ウォーターマークが表示されない、または位置が正しくない

位置情報ウォーターマークには位置情報へのアクセスが必要です。「システム設定 → プライバシーとセキュリティ → 位置情報サービス」で許可し、本アプリが位置情報を利用できるようにしてください。屋内や電波の弱い場所では位置情報が不正確になる場合があります。

天気ウォーターマークはどこで使えますか？

天気ウォーターマークはPro機能です。Proをアンロック後、天気を含むテンプレートを選択すると利用できます。天気データはApple WeatherKitによって提供されます。

Pro購入を復元するには？

Proを購入済みなのに有効にならない場合は、設定ページの「購入を復元」をタップしてください。それでも復元できない場合は、App Storeの購入レシートのスクリーンショットを添えてメールでお問い合わせください。
